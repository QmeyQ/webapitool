## openclaw 调用方式与限制（实测结论）

- CLI 必须从 `C:\Users\mey` 目录运行：在项目目录下 launch 信任文件写不进去直接失败
  （"trusted relative path could not be opened"）。后台运行（run_in_background）也会因 cwd 变化失败；
  长任务用 WMI 起 powershell 包一层：`Set-Location C:\Users\mey; openclaw agent --message-file ... --json > out.json`。
- openclaw 专用浏览器：启动参数强制 `--no-proxy-server`，需 `browser.extraArgs` 注入
  `--proxy-server=http://127.0.0.1:7897`（系统代理）；且窗口不可见（隐藏桌面），用户无法手动登录它。
  代理路由下导航还被 SSRF 策略挡，需 `browser.ssrfPolicy.dangerouslyAllowPrivateNetwork=true`。
- **登录态方案**：Edge 156+ 禁止在默认 user-data-dir 上开 CDP（--remote-debugging-port 被忽略）。
  可行做法：把用户的 Edge profile 复制到独立目录（robocopy Profile 8 + Local State，
  排除 Cache/Code Cache/GPUCache 等），WMI 启动
  `msedge --remote-debugging-port=9333 --user-data-dir=C:\Users\mey\edge-cdp --profile-directory="Profile 8"`，
  openclaw `browser.cdpUrl=http://127.0.0.1:9333` + `browser.attachOnly=true`，gateway restart 生效。
  Cookie 复制后 Lovart 登录态保留可用。
- **端口冲突教训**：中转的浏览器 CDP 默认端口也是 9222（browser_config.json DEFAULT_PORT），
  给 openclaw 的 Edge 占了 9222 会导致中转连错浏览器；openclaw 必须用其他端口（现用 9333）。
- **openclaw agent 自主执行不可用**：大脑是 poe Assistant（走 8199 中转），中转虽把 14 个工具
  注入提示词并上传（49k 系统提示词走文件上传策略），poe bot 坚称"没有可用工具"拒绝输出 tool_call
  ——它知道自己是 poe 机器人没有原生函数调用。内联工具协议到输入框文本也没用。
  openai 官方模型（gpt-5.4-mini 等）配置存在但认证失效。**结论：用 openclaw 的浏览器命令链路
  （browser open/snapshot/click/fill/upload/evaluate/download）由我直接驱动可行，agent 自主模式不可行。**
- gateway 是计划任务 "OpenClaw Gateway OpenClawFoundation...S-1-5-21-..." 启动的，
  挂了用 Start-ScheduledTask 全名拉起。
- PowerShell 传 JSON 参数会被转义搞坏，用 --fields-file / --message-file 传文件；
  隔离会话读不了 %TEMP%，临时文件放项目目录或 C:\Users\mey。

## poe 工作流导航慢（已修复，29s vs 之前 84-115s）

根因三层：
1. poe 工作流首步 NAVIGATE **每个请求都无条件整页重载** poe.com/Assistant
   （即使 tab 已在该页）；Route 阶段切模型也导航过一次 → 双重导航
2. Route 导航后死等 4s，poe 走代理加载 >25s → NAVIGATE 的跳过判定
   （2s 元素探测）失败 → 又重载一次
3. **大坑：裸 CSS 选择器直接 tab.ele() 会被 DrissionPage 当其他语法解析，
   永远找不到元素**（ElementFinder 的 _find_with_syntax 会自动加 css:
   前缀，裸调不会）。等待循环全部空转，30s+25s 白等
   （textarea[class*="GrowingTextArea"] 无前缀踩中此坑）

修复（browser_core.py）：
- 新增 `_drission_find(tab, selector, timeout)`：与 ElementFinder 同语法
  规则（裸 CSS 自动加 css: 前缀）
- NAVIGATE 步骤：URL 已在目标页时只等元素就绪（25s）不重载，元素就绪
  即 return 跳过；真没就绪才重载恢复
- Route 切模型导航后：等 input_box 就绪（30s）替代死等 4s

剩余耗时构成（30s 基线）：Route ~5s + fill/send 校验 ~8s + AI 回复 ~9s +
稳定尾巴 STREAM_STABLE_COUNT_THRESHOLD=10 次 ≈ 9s（所有站点共享，
